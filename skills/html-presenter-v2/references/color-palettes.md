# Color Palettes — HTML Presenter v2

Professional color palettes for web-based presentations. Each palette includes CSS custom property definitions ready to paste into `:root`.

---

## How to Choose a Palette

Match the palette to the **topic and audience** — not personal preference.

| Situation | Recommended Palette |
|-----------|-------------------|
| Investor/executive pitch | Midnight Executive, Charcoal Minimal, Deep Ocean |
| Product/tech presentation | Neon Circuit, Deep Ocean, Charcoal Minimal |
| Marketing/brand | Coral Punch, Cherry Bold, Sunset Warmth |
| Sustainability/environment | Forest & Moss, Sage Calm |
| Healthcare/wellness | Sage Calm, Teal Trust |
| Startup/energy | Coral Punch, Neon Circuit, Electric Violet |
| Finance/professional | Midnight Executive, Charcoal Minimal |
| Creative/design | Electric Violet, Paper & Ink, Sunset Warmth |
| Developer/technical | Neon Circuit, Terminal Dark |
| Education/academic | Warm Editorial, Sage Calm |

## Contrast Quick Reference

Minimum contrast ratios (WCAG):
- **4.5:1** — Normal text (body copy)
- **3:1** — Large text (24px+ or 18.5px bold+)

All palettes above are designed so that:
- `--color-text` on `--color-bg` → **>10:1** ✓
- `--color-text-light` on `--color-bg-dark` → **>7:1** ✓
- `--color-text-muted` on `--color-bg` → **>4.5:1** ✓

Always verify accent colors on their intended backgrounds before use.
